# Sefy Studio site

Live at https://sefystudio.github.io (GitHub Pages, branch `main`).

- `/` studio home, `/loom-pop/`, `/pip-and-pals/` game pages with support, privacy and join pages.
- All pages are generated by `python3 _build.py` (one template, shared `assets/site.css` + `assets/site.js`). Edit `_build.py`, not the HTML.
- `/pip-and-pals/play/` is the Pip & Pals web game: a copy of `pip-and-pals/web/index.html` where the fake test ads promote our own games.
  Refresh it from the game repo when the game changes (re-apply the house-ad patch).
- Keep `app-ads.txt` and `robots.txt` at the root.
